# Examples

Example scripts and vulnerable applications for testing.

## Files:

- `train_ml_models.py` - Train ML models for vulnerability detection
- `vulnerable_app.py` - Sample vulnerable application for testing
- `test_hexstrike_real_world.sh` - Real-world penetration testing script

## Usage:

```bash
# Train ML models
python examples/train_ml_models.py

# Run vulnerable test app
python examples/vulnerable_app.py

# Real-world testing
bash examples/test_hexstrike_real_world.sh
```
