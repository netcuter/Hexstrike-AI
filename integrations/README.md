# Integrations

Advanced LLM and ML integrations for Hexstrike.

## Files:

- **LLM Orchestrators**: Smart routing between multiple AI models
  - `hierarchical_llm_orchestrator.py` - Hierarchical model selection
  - `reverse_hierarchical_orchestrator.py` - Reverse hierarchy
  - `smart_orchestrator_with_fallback.py` - Smart routing with fallback
  - `dual_llm_integration.py` - Dual model integration

- **Specialized Integrations**:
  - `granite_solo_pure.py` - Pure Granite model integration
  - `granite_solo_real.py` - Real-world Granite integration
  - `hexstrike_lm_integration.py` - LM Studio integration
  - `hexstrike_ml_integration.py` - Machine Learning integration

- **MCP (Model Context Protocol)**:
  - `hexstrike_mcp_bridge.py` - MCP bridge implementation
  - `mcp_pentesting_server.py` - Pentesting MCP server
