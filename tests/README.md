# Tests

Comprehensive test suite for Hexstrike functionality.

## Test Files:

- `test_hexstrike_effectiveness.py` - Effectiveness testing
- `test_hexstrike_live.py` - Live penetration testing
- `test_ml_features.py` - Machine Learning features testing
- `test_security_fixes.py` - Security fixes validation
- `test_security_mini_server.py` - Mini test server

## Running Tests:

```bash
# Run all tests
python -m pytest tests/

# Run specific test
python tests/test_ml_features.py
```
